# Student Analytics Toolkit

A terminal-based menu program that generates, cleans, models, analyses, and reports on student data. Built as the capstone project for Python Essentials 2, this toolkit combines file handling, object-oriented programming, generators, closures, and the Python standard library into a single working pipeline.

## Author

Sandisiwe Luke — 2026 DS Cohort

## Features

- Generates a sample (intentionally messy) student data file
- Loads and cleans records from file using string methods
- Displays all loaded students
- Analyses data: class average, pass/fail counts, top student
- Filters students by pass/fail status using a generator
- Grades students against a custom pass mark using a closure
- Reports on the runtime environment and current date/calendar
- Exports analysis results to a report file
- Logs key actions with timestamps to an activity log
- Handles invalid input gracefully without crashing
